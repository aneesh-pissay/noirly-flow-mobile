DESIGN SYSTEM — DOT-MATRIX EDITORIAL, DARK MODE, MOBILE (apply exactly):
Colors:
- Background: true black (#000000)
- Secondary surfaces/cards: near-black (#0D0D0D), dashed borders (not solid)
- Text primary: off-white (#F5F5F5)
- Text secondary/muted: low-opacity white (~60%)
- No color accents anywhere — strictly grayscale/monochrome
Typography:
- Large numerals (counts, dates, timestamps): dot-matrix/pixel-grid style
- Headings: dotted/perforated letterform style, used selectively
- Body/labels: standard clean sans-serif
Layout & spacing:
- Single-column, minimum 44x44pt touch targets
- Dashed/perforated hairline borders for dividers, card outlines, row separators — never solid
- Bottom tab bar: 4 tabs (Inbox, Board, Search, Menu), active tab shown via fill-inversion (white background, black icon/label), thin dashed top border on the bar itself
- Circular avatars with dotted/perforated ring borders
- Sharp or minimally-rounded corners everywhere — no pill shapes, no heavy rounding
Interaction:
- Active/selected states: solid black-or-white fill inversion, never a color accent
- Buttons: solid inverted-fill blocks, sharp corners
- Swipe-left on list rows reveals quick actions behind a dashed-edge reveal
- No hover-only affordances (mobile has no hover) — use tap-to-expand or swipe instead
Tone: experimental, editorial-tech, strictly monochrome, no gradients/glow/shadows.
